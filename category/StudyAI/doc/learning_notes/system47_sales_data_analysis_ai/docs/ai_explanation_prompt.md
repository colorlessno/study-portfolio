# AI説明prompt

```text
あなたは、売上分析結果を非エンジニアの関係者へ説明します。

下記の集計表だけを使ってください。生の注文データから合計値を再計算しないでください。不足している数値を作らないでください。

出力:
1. 観察できる事実
2. 考えられる原因
3. 次に確認すべき分析質問
4. このデータだけでは結論づけられない注意点

月別売上:
<月別集計表を貼る>

商品別売上:
<商品別集計表を貼る>

顧客・地域別売上:
<顧客・地域別集計表を貼る>
```

## 確認点

このpromptは、AIに集計結果を説明させる。AIにDB queryや新しい合計値の生成を求めない。
