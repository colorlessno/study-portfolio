# Operation Check

## 基本操作

1. 初期17件が5件単位で表示されることを確認する。
2. next / prevでページを切り替える。
3. sortでnameの昇順・降順を比較する。
4. keyword検索とsortを組み合わせる。
5. 一致しないkeywordでemptyを確認する。
6. keywordを消すとpage 1へ戻ることを確認する。

## 境界値

- page 1でprevを押してもpage 0にならない。
- 17件では4ページ目が最終ページになる。
- 現実装は5ページ目以降へ進めてしまうため、データがあるのにempty表示になる。
- 1件だけ一致する検索でも、ページ番号とbutton状態が妥当か確認する。

## 改善後に再確認すること

- 最初のページではprev、最後のページではnextが無効になる。
- loading / empty / error / successを別の表示として識別できる。
- 検索、sort、ページ変更を繰り返しても範囲外ページにならない。
