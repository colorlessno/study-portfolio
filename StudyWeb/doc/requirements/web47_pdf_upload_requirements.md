# web47 PDFアップロード 要件定義

## 1. 目的

PDFファイルをアップロードし、メタデータ管理、サイズ制限、種類チェック、後続AI/RAG処理への入口を学ぶ。

## 2. 学習対象

- PDF upload
- MIME type
- file size limit
- metadata
- temporary storage
- validation

## 3. 作成する成果物

- PDFアップロード画面
- PDF検証API
- ファイルメタデータ表示
- エラー表示
- 後続処理メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | PDFファイルを選択してアップロードできる |
| FR-02 | サイズ制限を確認できる |
| FR-03 | MIME type と拡張子を確認できる |
| FR-04 | ファイル名、サイズ、hash等のメタデータを表示できる |
| FR-05 | 不正ファイル時にエラーを返せる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 学習用に小さいファイルで確認できる |
| NFR-02 | ファイル本体とDBメタデータの違いを説明できる |
| NFR-03 | セキュリティ注意点を明記する |

## 6. 対象外

- OCR / RAG実装
- S3保存
- ウイルススキャン
- PDF本文解析

## 7. 受入条件

- PDFアップロードの検証項目を説明できる
- メタデータ管理の必要性を説明できる
- AI入力ファイルとして扱う前の注意点を説明できる

## 8. 学習観点

- ファイルアップロードはセキュリティ事故につながりやすい
- 本体保存とメタデータ管理を分ける
- AI処理前に入力ファイルの品質確認が必要
