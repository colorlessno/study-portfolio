# 保存手段比較

| 保存手段 | 得意 | 苦手 | 主な用途 |
|---|---|---|---|
| file | 単純な保存、配布 | 同時更新、検索、整合性 | 設定、エクスポート |
| Excel | 人が直接編集する表 | 大量同時更新、履歴、権限 | 小規模管理、集計下書き |
| object storage | 大きいファイル保存 | 複雑な検索、行単位更新 | 画像、PDF、backup |
| RDB | 整合性、SQL、JOIN | 柔軟な階層構造、全文検索専用 | 業務DB |
| search DB | 全文検索、ランキング | 更新整合性、複雑な取引 | 文書検索 |
| DWH | 大量集計、分析 | 頻繁な行更新 | BI、分析 |
| vector DB | 類似検索、RAG | 厳密検索、根拠管理なしの回答 | AI検索 |
