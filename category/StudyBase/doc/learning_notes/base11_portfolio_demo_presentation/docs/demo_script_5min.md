# 5分demo script

## 構成

1. contextと問題。
2. main demo flow。
3. 重要な設計判断。
4. failureまたはedge case。
5. 検証証拠。
6. 制限と次step。

## 時間配分

| 時間 | 内容 |
| ---: | --- |
| 0:00-0:40 | context |
| 0:40-2:00 | main demo |
| 2:00-3:00 | architecture と decision |
| 3:00-3:40 | failure または edge case |
| 3:40-4:30 | 検証証拠 |
| 4:30-5:00 | 制限と次step |

## 追加する価値

5分版では、feature主張を増やすのではなく、証拠とtradeoffを増やす。
