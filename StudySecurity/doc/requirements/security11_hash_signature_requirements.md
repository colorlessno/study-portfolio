# security11 ハッシュと署名 要件定義

## 1. 目的

ハッシュ、パスワードハッシュ、署名の違いを理解する。

## 2. 学習対象

- hash
- password hash
- salt
- digital signature
- HMAC / JWT署名の入口

## 3. 作成する成果物

- ハッシュ計算サンプル
- password hash説明
- 署名・検証サンプル
- 用途比較表

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | 同じ入力から同じhashが出ることを確認できる |
| FR-02 | パスワード保存に単純hashだけでは不足と説明できる |
| FR-03 | 署名と検証を確認できる |
| FR-04 | hashと暗号化を混同しない説明ができる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 実パスワードを使わない |
| NFR-02 | 学習用の単純例と本番推奨を分ける |
| NFR-03 | 秘密鍵の扱いに注意する |

## 6. 対象外

- 暗号理論の深掘り
- PKI全体
- 本格鍵管理

## 7. 受入条件

- hash、password hash、署名の用途を説明できる
- 署名は改ざん検出に使うと説明できる
- password hashには専用アルゴリズムが必要と説明できる

## 8. 学習観点

- hashは戻せないが秘密ではない
- 署名は真正性確認に使う
- パスワードは平文保存しない
