# StudyDB

データベースの基礎を、要件定義から設計・確認まで段階的に学ぶための個人学習用プロジェクトです。`db01`〜`db07` の各テーマに、要件定義・基本設計・詳細設計の文書と学習ノートを揃えています。

## 取り扱うテーマ

| 番号 | テーマ |
|------|--------|
| db01 | DB 基礎 |
| db02 | SQL CRUD / スキーマ |
| db03 | 正規化 / ER モデリング |
| db04 | トランザクション / ロック / 分離レベル |
| db05 | インデックス / EXPLAIN / 性能 |
| db06 | バックアップ / リストア / マイグレーション |
| db07 | NoSQL / キャッシュ / 検索 / DWH |

## 構成

```text
StudyDB/
  doc/
    requirements/      各テーマの要件定義
    basic_design/      基本設計
    detailed_design/   詳細設計
    learning_notes/    学習ノート・コマンド例
```

## 本リポジトリについて

- 個人の学習用に作成している実験的なプロジェクトです。
- 開発・整理には Claude Code / Codex などの AI コーディングアシストを活用しています。
- 学習目的のため、各テーマの粒度や完成度には差があります。
## 文書完結型テーマについて

`db01`（DB基礎）、`db03`（正規化・ERモデリング）、`db07`（NoSQL/キャッシュ/検索/DWH）は、詳細設計の製造対象を**コードではなく文書**（`doc/learning_notes/` 配下）として定義した文書完結型テーマです。SQL 教材コードがあるのは `db02` / `db04` / `db05` / `db06`（`src/apps/` 配下）です。
