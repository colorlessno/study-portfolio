# review対象

## 対象

| 項目 | 値 |
| --- | --- |
| system | 小さな StudyWeb または StudyDevOps sample |
| reviewする動作 | 1つのroute、job、compose flow、data path |
| review観点 | correctness、operability、security、performance、maintainability のいずれか |
| 証拠範囲 | 現在のrepository状態 |

## 対象外

- 無関係なmodule
- styleだけの好み
- 対象動作に不要な将来feature

## review質問

この設計が間違っていた場合、learner または operator にどんな問題が起きるか。
