# web06_form_basic

入力フォームと基本的なバリデーションを確認するサンプルです。

## 起動方法

`index.html` をブラウザで開きます。

## 入力チェック

| 項目 | チェック |
|---|---|
| 名前 | 必須 |
| メールアドレス | 必須、メール形式 |
| 問い合わせ種別 | 必須 |
| 本文 | 必須 |

## 確認ポイント

- 未入力で送信すると項目ごとにエラーが出る
- 不正なメールアドレスでエラーが出る
- 正常入力時に成功メッセージが出る
- リセットで入力値とメッセージが初期化される

実際のメール送信やAPI通信は行いません。
