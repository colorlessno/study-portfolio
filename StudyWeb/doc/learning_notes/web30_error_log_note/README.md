# web30_error_log_note

学習中に発生したエラーを再利用できる知識として残すためのMarkdownテンプレートです。

## ファイル

- `error-log-template.md`: エラー記録用テンプレート
- `examples/css-not-loaded.md`: CSSパス不一致の例
- `examples/api-404.md`: APIパス不一致の例

## 使い方

1. `error-log-template.md` をコピーする
2. エラー内容、再現手順、原因、解決方法を書く
3. タグを付けて後から検索しやすくする

## 記録時の注意

- エラーメッセージはコードブロックに貼る
- 再現手順は他の人が追える粒度にする
- 原因と解決方法を分けて書く
- APIキー、パスワード、個人情報、実在の接続文字列は書かない

DevToolsのConsole、Network、ターミナルログを見た場所も残すと、次に同じ問題が起きたときに早く切り分けできます。
