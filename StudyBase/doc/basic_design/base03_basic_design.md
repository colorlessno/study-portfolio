# base03 見積もり根拠表 基本設計
## 0. 関連要件

- `../requirements/base03_estimate_basis_requirements.md`

## 1. 設計目的
見積もりを日数だけでなく、範囲、前提、除外、作業分解、リスクで説明する学習サンプルを設計する。
## 2. 対象範囲

- 見積もり対象範囲の整理
- 除外範囲の明示
- 作業分解表の作成
- リスクと再見積もり条件の整理

## 4. 入力
| 入力 | 内容 |
|---|---|
| 作業依頼 | 見積もり対象の依頼 |
| 対象範囲 | 対応する機能、文書、調査範囲 |
| 制約 | 期限、環境や担当範囲、未確定事項 |

## 5. 出力
| 出力 | 内容 |
|---|---|
| 見積もり根拠表 | 工数と根拠を紐づけた表 |
| 作業分解表 | 調査、設計、実装、テスト、レビューの分解 |
| 前提・除外事項 | 見積もりの条件 |
| リスク一覧 | 変動要因と影響 |

## 6. 処理方針
1. 対象範囲と除外範囲を先に固定する
2. 作業を工程単位へ分解する
3. 各作業の根拠を記録する
4. 不確実性とリスクを明示する
5. 再見積もり条件を定義する

## 7. 確認観点

- 除外範囲が書かれているか
- 見積もり値に根拠があるか
- 前提が崩れた場合の扱いがあるか
## 8. 後続工程への引き継ぎ

詳細設計では、見積もり表の列、作業粒度、リスク分類、再見積もり条件を定義する。
