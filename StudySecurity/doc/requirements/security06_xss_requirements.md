# security06 XSS体験と対策 要件定義

## 1. 目的

ユーザー入力をHTMLとして扱う危険性を体験し、安全な表示方法を学ぶ。

## 2. 学習対象

- XSS
- HTML escape
- `innerHTML`
- textContent
- CSPの入口

## 3. 作成する成果物

- 危険な表示例
- 安全な表示例
- 攻撃文字列サンプル
- 対策メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | ユーザー入力を危険に表示する例を確認できる |
| FR-02 | 安全な表示例を確認できる |
| FR-03 | `innerHTML` と `textContent` の違いを確認できる |
| FR-04 | 入力値保存後に表示されるXSSを説明できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 攻撃例はローカル学習用に限定する |
| NFR-02 | 外部へ送信するコードを含めない |
| NFR-03 | 防御策を必ず併記する |

## 6. 対象外

- ブラウザ脆弱性
- CSP本格設計
- WAF

## 7. 受入条件

- XSSがなぜ危険か説明できる
- 危険な表示と安全な表示を比較できる
- 入力時だけでなく出力時の対策が必要と説明できる

## 8. 学習観点

- ユーザー入力は信用しない
- HTMLとして解釈させない
- 保存済みデータの表示でもXSSは起きる
