# base01 曖昧依頼ヒアリング

曖昧な依頼を、目的、現状、課題、制約、成功条件、未確定事項へ分け、解決策を決める前の入力を整えます。

## 到達目標

- 依頼原文と自分の解釈を区別できる。
- 確定情報、仮定、未確定事項を分類できる。
- 次に誰へ何を確認するかを残せる。

## 始める前の問い

- 「取りこぼし」とは、誰のどの状態を指すか。
- CRM導入は確定事項か、解決案の候補か。
- 成功を何で測り、誰が判断するか。

## 15分で再開

```powershell
node StudyBase\scripts\validate-studybase.mjs base01
```

曖昧依頼を読み、確定・仮定・未確定を各2件書いてから記入例と比較します。記入例を正解として写さず、差の理由を1つ説明します。

## 完了条件

解決策を決め打ちせず、成功条件と次の確認相手を含むヒアリングメモを作れれば完了です。
