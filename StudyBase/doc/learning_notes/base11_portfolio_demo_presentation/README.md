# base11 ポートフォリオdemo発表

## 目的

学習projectを、証拠、制限、短いdemo storyと一緒に説明する方法を学ぶ。

projectを大きく見せることが目的ではない。何を作り、何を確認し、何を学んだかを伝わりやすくする。

## 学習順

1. `docs/target_selection.md` で対象を選ぶ。
2. `docs/evidence_selection.md` で証拠を選ぶ。
3. 60秒scriptを書く。
4. 3分script、5分scriptへ広げる。
5. `docs/limitation_note.md` で制限を書く。
6. `docs/video_structure.md` で動画構成を決める。

## 完了条件

- demoは実際のuserまたはoperatorの結果から始まる。
- 主張はfile、command、screenshot、test resultなどで裏づける。
- 制限を明示する。
- 作ったものと今後作るものを分ける。
