# API 404

## 基本情報

- 発生日: 2026-04-28
- サンプル名: web21_network_debug
- 環境 Docker Compose
- 関連ファイル: `src/frontend/src/main.tsx`, `src/backend/src/main.ts`
- タグ: `api`, `404`, `network`

## エラー内容

```text
GET http://localhost:13021/status/missing 404 (Not Found)
```

## 再現手順
1. Web画面を開く
2. 存在しないAPIパスを呼ぶ
3. DevTools の Network タブで404を確認する
## 原因

フロントエンドが呼んでいる URL と、バックエンドに実装されているエンドポイントが一致していなかった。
## 解決方法
フロントエンドの URL を実装済みの `/status/not-found` に合わせた。
## 次回確認ポイント
- API一覧とフロントの呼び出し元が一致しているか
- 404はネットワーク断ではなくルーティング不一致でも発生する
