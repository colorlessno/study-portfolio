# web40 テーブル検索・ページング 要件定義

## 1. 目的

業務一覧画面に必要な検索、並び替え、ページング、empty / loading / error state を実装する。

## 2. 学習対象

- table UI
- search form
- sort
- pagination
- loading / empty / error
- keyboard and accessibility basics

## 3. 作成する成果物

- 一覧テーブル画面
- 検索条件
- 並び替え
- ページング
- 画面状態表示

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | テーブル形式で一覧を表示できる |
| FR-02 | キーワード検索ができる |
| FR-03 | 列による並び替えができる |
| FR-04 | ページングできる |
| FR-05 | loading / empty / error を表示できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 長い文字列でレイアウトが崩れない |
| NFR-02 | キーボード操作を考慮する |
| NFR-03 | 業務UIとして情報を読み取りやすい |

## 6. 対象外

- 仮想スクロール
- 大量データ性能最適化
- DB連携

## 7. 受入条件

- 一覧画面の基本状態を説明できる
- 検索、ソート、ページングの組み合わせを確認できる
- データなしやエラー時の表示を確認できる

## 8. 学習観点

- 業務一覧は状態設計が重要
- ページングなしで全件表示しない
- empty state はエラーではない
