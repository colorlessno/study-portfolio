# base03 見積もり根拠表 要件定義

## 1. 目的

見積もりを単なる日数回答にせず、対象範囲、除外範囲、前提、作業項目、リスク、未確定事項に分解して説明できるようにする。

## 2. 学習対象

- 見積もり対象範囲の定義
- 除外範囲の明示
- 前提条件と未確定事項の扱い
- 作業分解と粒度
- リスクとバッファの説明

## 3. 作成する成果物

- 見積もり根拠表テンプレート
- 作業分解表
- 前提・除外事項一覧
- リスク一覧
- 見積もり変更条件メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | 見積もり対象と対象外を記録できる |
| FR-02 | 作業項目を調査、設計、実装、テスト、レビューに分けられる |
| FR-03 | 各作業の見積もり根拠を記録できる |
| FR-04 | 前提が崩れた場合の再見積もり条件を記録できる |
| FR-05 | リスクと影響を記録できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | Markdown の表で管理できる |
| NFR-02 | 根拠がない数値を断定しない |
| NFR-03 | 後続の要件変更時に更新しやすい |

## 6. 対象外

- 高精度な工数見積もり手法の網羅
- 原価計算
- 契約条件の作成
- 実装

## 7. 受入条件

- 見積もり対象、対象外、前提、リスクが分かれている
- 作業項目ごとに根拠が記載されている
- 再見積もりが必要になる条件が明記されている
- 情報不足による不確実性が見える形になっている

## 8. 学習観点

- 見積もりは日数だけでなく根拠と前提を示す
- 除外範囲を書かない見積もりは誤解を生む
- 不確実性を隠さず管理する
