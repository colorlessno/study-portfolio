# Table State

| 状態 | 意味 | 利用者への表示 | 現実装 |
|---|---|---|---|
| loading | データ取得・処理中 | 読込み中、操作待ち | 未実装 |
| success | 1件以上を表示できる | table、件数、ページ | 実装済み |
| empty | 正常に処理した結果が0件 | 条件変更等の案内 | 実装済み |
| error | 取得・処理に失敗 | 原因の概要、再試行 | 未実装 |

empty は正常な検索結果であり、error と同じ表示・扱いにしない。

現在は最終ページを越えても `next` を押せるため、範囲外ページが empty と同じ表示になる。これは本当の0件とページ制御不備を区別できない状態なので、総ページ数の計算とbutton無効化が必要。
