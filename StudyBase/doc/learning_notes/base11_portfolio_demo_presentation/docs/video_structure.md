# 動画構成

## shot list

| segment | screen |
| --- | --- |
| opening | app、command、またはresult screen |
| problem | 短いtitleまたはREADME section |
| demo | 実際のworkflow |
| architecture | diagramまたはfolder map |
| verification | test、command、またはlog |
| limitation | next step付きの短いnote |

## recording checklist

- 無関係なwindowを閉じる。
- 読みやすいfont sizeにする。
- terminal outputを絞る。
- 大きなfileを長くscrollしない。
- 実装詳細を説明する前に結果を見せる。

## 最終確認

録画後に、視聴者が以下を答えられるか確認する。

1. 何の問題を解くものか。
2. 何を作ったか。
3. どう検証したか。
4. 何がまだ制限か。
