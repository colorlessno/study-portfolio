# base05 RACI / 責任分界表 要件定義

## 1. 目的

責任範囲が曖昧な作業について、誰が実施し、誰が承認し、誰へ相談し、誰へ共有するかを整理できるようにする。

## 2. 学習対象

- RACI の基本
- 実施責任と説明責任の違い
- 決定者、実施者、確認者、共有先の分離
- 責任分界が曖昧な依頼への対応
- エスカレーション事項の整理

## 3. 作成する成果物

- RACI表テンプレート
- 責任分界表
- エスカレーションメモ
- 判断待ち事項一覧
- 役割定義メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | 作業項目ごとに Responsible / Accountable / Consulted / Informed を記録できる |
| FR-02 | 決定権が不明な事項を判断待ちとして記録できる |
| FR-03 | 自分で決めてよい範囲と決めてはいけない範囲を分けられる |
| FR-04 | エスカレーション先と理由を記録できる |
| FR-05 | 関係者への共有事項を整理できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | Markdown の表で読み書きできる |
| NFR-02 | 責任追及ではなく作業分担の明確化を目的にする |
| NFR-03 | 要件定義、設計、テスト、運用の各工程で使い回せる |

## 6. 対象外

- 組織全体の職務分掌作成
- 契約上の責任範囲確定
- 人事評価
- 実装

## 7. 受入条件

- 作業ごとの実施者、承認者、相談先、共有先が分かる
- 判断待ち事項とエスカレーション理由が明記されている
- 自分の責任範囲と範囲外が分けられている
- 後続作業の停滞理由を説明できる

## 8. 学習観点

- 誰が決めるか分からない作業を自分だけで抱えない
- 責任分界は文書で見える化する
- 判断待ちは放置ではなく管理対象にする
