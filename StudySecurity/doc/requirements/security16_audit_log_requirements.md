# security16 監査ログ 要件定義

## 1. 目的

誰が、いつ、何をしたかを追跡する監査ログの基本を学ぶ。

## 2. 学習対象

- audit log
- actor
- action
- target
- before / after
- request id

## 3. 作成する成果物

- 監査ログサンプル
- ログ項目定義
- 操作履歴画面または出力
- 個人情報を出しすぎないメモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | login / update / delete操作を記録できる |
| FR-02 | actor, action, target, timestampを記録できる |
| FR-03 | request idを記録できる |
| FR-04 | 監査ログを確認できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | パスワードやtokenをログに出さない |
| NFR-02 | 改ざんしにくい保存が本番では必要と説明する |
| NFR-03 | 業務ログとデバッグログの違いを説明する |

## 6. 対象外

- SIEM連携
- 改ざん耐性ストレージ
- 長期保存設計

## 7. 受入条件

- 監査ログの主要項目を説明できる
- 誰が何をしたかを追跡できる
- ログに出してはいけない情報を説明できる

## 8. 学習観点

- セキュリティ事故後はログが重要
- 監査ログはデバッグログとは目的が違う
- 秘密情報をログに出さない
