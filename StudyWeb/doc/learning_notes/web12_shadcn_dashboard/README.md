# web12_shadcn_dashboard

shadcn/ui 風の管理画面を React + Tailwind CSS で作るサンプルです。

## 起動方法

```bash
npm install
npm run dev
```

## コンポーネント

- `AppSidebar`: サイドナビゲーション
- `Header`: ヘッダーと操作ボタン
- `StatCard`: 指標カード
- `DataTable`: 一覧テーブル

## 確認ポイント

- 管理画面らしいサイドバー、指標カード、テーブル構成になっている
- Tailwind CSSで見た目を調整している
- lucide-react のアイコンを使っている
