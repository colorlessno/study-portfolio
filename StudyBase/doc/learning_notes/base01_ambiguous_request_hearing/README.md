# base01 曖昧依頼ヒアリング

## 目的
曖昧な依頼を、目的、現状、課題、制約、成功条件、未確定事項に分類する練習です。
## 使い方

1. `../../../src/samples/base01_ambiguous_request_hearing/ambiguous_request_case.md` を読む
2. `../../templates/base01_ambiguous_request_hearing/request_hearing_note.md` の観点で整理する
3. `../../../src/samples/base01_ambiguous_request_hearing/completed_hearing_note.md` と比較する
4. `../../templates/base01_ambiguous_request_hearing/requirement_input_summary.md` へ要件定義に渡す情報をまとめる

## 確認ポイント
- 依頼原文を勝手に仕様化していないか
- 確定情報、仮定、未確定事項が分類されている
- 次に誰へ何を確認するかが残っている
