# base02 情報不足時の暫定成果物

## 目的
情報不足でも、書ける範囲、書けない範囲、前提、未確定事項、成果物の限界を分けた暫定成果物を作る練習です。
## 使い方

1. `../../../src/samples/base02_incomplete_information_deliverable/incomplete_case.md` を読む
2. `../../templates/base02_incomplete_information_deliverable/` の各テンプレートに分類する
3. `../../../src/samples/base02_incomplete_information_deliverable/completed_provisional_deliverable.md` と比較する

## 確認ポイント
- 不明点を断定していないか
- 仮定に根拠と影響がある
- 成果物の利用範囲と限界が明記されている
