# web52 現代Web表示方式の比較

## 目的

同じ画面を題材に、代表的なWeb表示方式を比較し、選定基準を説明できるようにする。

この単元は文書比較を先に行う。選定基準が明確になるまでは、新しいアプリ実装を増やさない。

## 学習順

1. `docs/rendering_mode_matrix.md` を読む。
2. `docs/list_screen_comparison.md` で同じ一覧画面を比較する。
3. `docs/api_cache_auth_relation.md` で API、cache、auth、hydration の関係を見る。
4. `docs/studyweb_mapping.md` で既存 StudyWeb 単元とのつながりを確認する。
5. `docs/selection_scenarios.md` で選定練習をする。

## 完了条件

- MPA、SPA、SSR、SSG、server components、islands、PWAを、どれか1つが常に最善だとせず説明できる。
- user flow、data freshness、auth、cache、interactivity から表示方式を選べる。
