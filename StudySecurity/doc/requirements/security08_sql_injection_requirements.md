# security08 SQL Injection体験と対策 要件定義

## 1. 目的

文字列連結SQLの危険性と、パラメータ化による対策を学ぶ。

## 2. 学習対象

- SQL Injection
- string concatenation
- parameterized query
- ORMの安全な使い方
- 入力値検証

## 3. 作成する成果物

- 危険なSQL例
- 安全なSQL例
- 攻撃入力例
- 対策メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | 文字列連結SQLの危険性を確認できる |
| FR-02 | パラメータ化SQLで防げることを確認できる |
| FR-03 | 認証回避や全件取得の例を説明できる |
| FR-04 | エラーでSQL詳細を出さないことを確認できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 学習用DBまたは疑似実装に限定する |
| NFR-02 | 危険例と安全例を必ず並べる |
| NFR-03 | 実システムへ攻撃しない注意を明記する |

## 6. 対象外

- DB権限設計
- WAF
- 高度なSQLチューニング

## 7. 受入条件

- SQL Injectionの成立理由を説明できる
- パラメータ化の意味を説明できる
- エラーメッセージで内部情報を出さない理由を説明できる

## 8. 学習観点

- 入力値をSQL文字列に直接連結しない
- ORMでも危険な書き方はある
- エラー表示も情報漏洩になる
