# web31_issue_pr_style

Issue / PR 風の作業記録テンプレートです。作業の背景、目的、変更内容、影響範囲、確認結果を説明する練習に使います。

## ファイル

- `issue-template.md`: Issue作成用テンプレート
- `pr-template.md`: PR説明用テンプレート
- `examples/sample-issue.md`: Webサンプル作成を題材にしたIssue例
- `examples/sample-pr.md`: 小さな修正を題材にしたPR例

## 使い方

1. 作業前に `issue-template.md` をコピーし、背景、目的、やること、完了条件を書く
2. 作業後に `pr-template.md` をコピーし、変更概要、理由、影響範囲、確認結果を書く
3. チェックリストで未確認項目を残さないようにする

## 記入時の注意

- 背景と目的を分けて書く
- 変更内容と変更理由を分けて書く
- 影響範囲に画面、API、DB、ドキュメントを含める
- 確認結果は実際に確認した内容だけにする

GitHub Actionsや自動レビューは対象外です。
