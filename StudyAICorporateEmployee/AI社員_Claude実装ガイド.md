# ローカルPCでAI社員を作る — Claude Code + CLAUDE.md

## 結論：可能です

「MDファイルを置くだけ」は**ほぼ正確**です。  
正確には `CLAUDE.md` という特定のファイル名を決まった場所に置くと、Claude Code がそれを読んで「そのAI社員として振る舞う」仕組みです。

---

## 仕組みの全体像

```
プロセス1: claude --model claude-sonnet-4-6
  └── ./employee_hr/CLAUDE.md  ← 人事AI社員の指示書

プロセス2: claude --model claude-sonnet-4-6
  └── ./employee_sales/CLAUDE.md  ← 営業AI社員の指示書
```

**CLAUDE.md = AI社員の「辞令＋業務マニュアル」**  
これを置いてClaudeを起動すれば、そのAIはその役割として会話します。  
コードは一切不要です。

---

## 必要なもの

| 項目 | 内容 |
|------|------|
| インストール | `npm install -g @anthropic-ai/claude-code` |
| APIキー | `ANTHROPIC_API_KEY` を環境変数にセット |
| ファイル | 役割ごとに `CLAUDE.md` を書くだけ |

---

## CLAUDE.md サンプル — 人事AI社員

ファイルパス: `./employee_hr/CLAUDE.md`

```markdown
# 役割
あなたは株式会社〇〇の人事部AI社員「田中 HR」です。

## あなたの業務
- 採用・入退社手続きの案内
- 就業規則・有給休暇の説明
- 社内研修の調整
- 給与・福利厚生に関する一般的な質問への回答

## 対話スタイル
- 丁寧で親しみやすいビジネス敬語を使う
- 不明点は「確認してご連絡します」と答える
- 個人情報に関わる質問は人間の担当者に引き継ぐ

## 制約
- 実際の給与額や個人の評価には言及しない
- 法的判断が必要な案件は社労士への相談を勧める
```

## CLAUDE.md サンプル — 営業AI社員

ファイルパス: `./employee_sales/CLAUDE.md`

```markdown
# 役割
あなたは株式会社〇〇の営業部AI社員「佐藤 Sales」です。

## あなたの業務
- 製品・サービスの説明と提案
- 見積もり依頼の受付と整理
- 商談スケジュールの調整サポート
- 顧客からのよくある質問への回答

## 対話スタイル
- 提案型の会話を心がける
- 顧客のニーズを引き出す質問をする
- 価格交渉は「上長に確認します」と伝えてエスカレーション

## 持っている知識（ここに製品情報を書く）
- 製品A: 月額10,000円、〇〇機能あり
- 製品B: 月額30,000円、〇〇〇機能あり
```

---

## 起動方法（2つのターミナルで別々に実行）

**ターミナル1 — 人事AI社員を起動**
```bash
cd employee_hr
claude
```

**ターミナル2 — 営業AI社員を起動**
```bash
cd employee_sales
claude
```

これだけで、それぞれ独立したプロセスとして動きます。

---

## できること・できないこと

### ✅ できる（MDファイルのみ）
- 役割・人格・口調の定義
- 業務スコープの制限（「採用の質問だけ答える」など）
- 知識の埋め込み（製品情報、FAQ、社内規定など）
- 複数プロセスでの同時起動
- 社内ツール（ファイル、コマンド）への操作権限制御

### ⚠️ 追加設定が必要なもの
- **2人のAI社員が互いに会話する**  
  → 一方のAIが他方を呼び出す「サブエージェント」設定が必要（CLAUDE.mdに書ける）
- **外部システム連携**（Slackで受け取る、DBを検索するなど）  
  → MCPサーバー設定（`.claude/settings.json`）が別途必要
- **常時起動・自動応答**  
  → `claude --print` をバッチで呼ぶか、Agent SDKでラップする

---

## AI社員同士が会話するパターン（上級）

CLAUDE.mdに「サブエージェント呼び出し」を書くことで、  
人事AIが営業AIに仕事を「依頼」する構造も作れます。

```markdown
## 連携ルール（employee_hr/CLAUDE.md に追加）
営業部への引き継ぎが必要な場合は、以下の情報をまとめて
Taskツール経由で営業エージェント（employee_sales/）に依頼すること。
```

## まとめ

| 旧来の方法 | CLAUDE.md方式 |
|-----------|--------------|
| 役割をコードで実装 | 日本語で書くだけ |
| フロー設計が必要 | 「〇〇の場合は〇〇して」と書くだけ |
| デプロイ・テストが大変 | ファイルを保存してclaudeを起動するだけ |
| 変更にエンジニアが必要 | テキスト編集で即反映 |

**まず試すなら**：上記の `employee_hr/CLAUDE.md` をコピーして  
`claude` コマンドで起動するだけです。5分で動きます。
