# security12 SSH鍵 / JWT署名鍵 要件定義

## 1. 目的

公開鍵・秘密鍵の役割と、SSH鍵、JWT署名鍵の扱いを学ぶ。

## 2. 学習対象

- public key / private key
- SSH key
- JWT signing key
- key permission
- key leakage

## 3. 作成する成果物

- 鍵の役割メモ
- SSH鍵確認手順
- JWT署名鍵サンプル
- 秘密鍵保護チェックリスト

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | 公開鍵と秘密鍵の役割を説明できる |
| FR-02 | SSH公開鍵を登録する流れを説明できる |
| FR-03 | JWT署名鍵の漏洩リスクを説明できる |
| FR-04 | 秘密鍵を共有してはいけない理由を説明できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 実秘密鍵を作成・保存しない |
| NFR-02 | サンプル鍵はダミー表記にする |
| NFR-03 | 鍵漏洩時は失効・再発行が必要と説明する |

## 6. 対象外

- 実GitHub SSH設定
- 証明書チェーン
- HSM / KMS本格運用

## 7. 受入条件

- 公開鍵と秘密鍵の違いを説明できる
- SSH鍵とJWT署名鍵の用途を説明できる
- 秘密鍵漏洩時の危険性を説明できる

## 8. 学習観点

- 公開鍵は配れるが秘密鍵は守る
- JWT署名鍵が漏れると偽tokenを作られる
- 鍵はファイル権限と保管場所が重要
